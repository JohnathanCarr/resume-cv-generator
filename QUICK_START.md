# ⚡ Quick Start

**You need an OpenAI API key.** Get one at https://platform.openai.com/api-keys — generation is billed to your OpenAI account, a few cents per document.

## 1. Install (two minutes, nothing to run)
1. **Download ZIP** from GitHub → extract it somewhere permanent (Chrome loads the extension from this folder)
2. Open `chrome://extensions/`
3. Enable **Developer mode** (top-right toggle)
4. Click **Load unpacked** → select the **`extension`** folder
5. Click the extension icon — it opens in its own tab

## 2. Add your key
Click the **gear icon**, paste your OpenAI key, **Save key**. It shows **Verified** when OpenAI accepts it.

## 3. Generate
1. **Upload your resume** (PDF) to autofill your profile, then review and complete it
2. **Paste a job description** in the Generate tab
3. **Generate Cover Letter** (tick **Research the company** for sourced facts about the employer) or **Generate Resume**
   - If the posting names skills your profile doesn't mention, a dialog lists them: tick the ones you have, then **Continue**
   - Later resumes revise the last one rather than starting over; untick **Revise the last resume** for a fresh draft
4. **Cover Letter PDF** downloads directly; **Resume PDF** opens a print view — choose **Save as PDF**

## Pro tips
- **Mark "Must Include"** on experiences/projects to guarantee they appear on resumes
- **Classify extras** as Research/Program/Certification
- **Upload a new resume** any time — new items are added, nothing is removed
- **Keep your profile complete** — each document picks what fits the job
