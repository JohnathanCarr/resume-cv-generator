# Quick Start

**You need an OpenAI API key.** Get one at https://platform.openai.com/api-keys. Generation is billed to your OpenAI account at OpenAI's API prices, a few cents per document; Resume Studio itself is free.

## 1. Install (two minutes, nothing to run)
1. **Download ZIP** from GitHub and extract it somewhere permanent (Chrome loads the extension from this folder)
2. Open `chrome://extensions/`
3. Enable **Developer mode** (top-right toggle)
4. Click **Load unpacked** and select the **`extension`** folder
5. Click the extension icon: it opens in its own tab

## 2. Add your key
Click the **gear icon**, paste your OpenAI key, then **Save key**. It shows **Verified** when OpenAI accepts it.

## 3. Generate
1. **Upload your resume** (PDF) in the Profile tab. It is read in your browser and fills in your profile; review and complete it, then **Save profile**
2. **Paste a job description** in the Generate tab
3. **Generate cover letter** (tick **Research the company** for sourced facts about the employer) or **Generate resume**
   - A progress bar above the posting and preview shows the run; it turns green when done
   - If the posting names skills your profile doesn't mention, a dialog lists them: tick the ones you actually have, then **Continue**
   - Every resume starts from the one you uploaded, tailored to this posting and kept to one page
4. **Read it through.** On a resume, changes are underlined in green (hover one to see the original); **Tailored / Original** switches to your uploaded resume for comparison
5. **Cover letter PDF** downloads directly; **Resume PDF** opens a print view: choose **Save as PDF**. Both ask for a file name first

## Pro tips
- **Tick "Must include"** on the experiences and projects that matter most: it is a strong hint to the generator, not a guarantee
- **Classify extras** (certification, award, research, program and more) so they land in the right place
- **Upload a new resume** any time: it becomes the starting point for tailoring, and only new items are added to your profile; nothing is removed
- **Keep your profile complete**: each document picks what fits the job
- **Replay the tour** with the **?** button in the header
